# Edmond Garcia — Cybersecurity Class Code Portfolio

A presentation-ready master index for the classroom simulations, learning tools, and code projects in the `eygarcia` GitHub account.

## Publish with GitHub Pages

1. Create a new public GitHub repository (recommended name: `class-code-portfolio`).
2. Upload the file at `dist/index.html` to the top level of the repository and keep its name as `index.html`.
3. In the repository, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, choose **main**, select **/(root)**, and save.
5. Your portfolio will appear at `https://eygarcia.github.io/class-code-portfolio/`.

All CSS, JavaScript, project data, and the favicon are embedded in one HTML file, so there are no external assets to manage.

## Updating the project list

Edit the `projects` array near the bottom of `index.html`. Each entry controls the title, repository, category, description, tags, and whether a GitHub Pages demo button appears.
